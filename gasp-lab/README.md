# Blurpest — laboratorio GSAP

Sito demo di uno studio grafico immaginario, creato da IkodaI Studio per mostrare ai clienti cosa si può fare con le animazioni web (GSAP 3 con ScrollTrigger, SplitText, ScrambleText, Flip, Draggable e Inertia).

- Sito statico, nessuna build: si apre `index.html`.
- GSAP e caratteri sono copiati in `assets/`, nessun servizio esterno.
- Tutte le animazioni si spengono se il dispositivo chiede movimento ridotto.
- Blurpest non esiste: nomi, lavori e testi sono inventati.
